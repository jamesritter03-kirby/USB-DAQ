Installing

Windows — download and run the installer, that's it.

  1. Click Download for Windows above.
  2. Run USB-DAQ-Setup.exe. It installs per-user (no admin prompt).
  3. Launch from the Start Menu or desktop shortcut.

macOS — open the .dmg and drag USB DAQ into Applications.

  1. Download the Apple Silicon or Intel .dmg above.
  2. Open it and drag the app to Applications.
  3. First launch: right-click the app → Open (the build is unsigned).

Linux — one self-contained AppImage, nothing to install.

  1. Download USB-DAQ-Linux-x86_64.AppImage above.
  2. Make it executable: chmod +x USB-DAQ-Linux-x86_64.AppImage.
  3. Run it (double-click, or ./USB-DAQ-Linux-x86_64.AppImage).

The app checks for new versions on startup and can update itself with one click — no need to come back here for future releases.
